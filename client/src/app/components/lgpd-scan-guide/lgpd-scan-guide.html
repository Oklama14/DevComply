Comparar com o código usando a lgpd-scan

O checklist registra o que vocês declaram. A lgpd-scan é uma skill para agentes de código (Claude Code, Codex, Gemini CLI, Cursor e OpenCode) que lê o código do projeto e mostra o que está de fato implementado. Ela roda no seu computador: o código não passa pelo DevComply.

  1. 1

    Instale a lgpd-scan só na primeira vez

    Precisa de Git e de Python 3.8 ou mais recente. No terminal (no Windows, o PowerShell):

    {{ instalar[sistema] }}

    O instalador encontra os agentes que você usa e deixa a skill valendo em todos os projetos. Instruções completas no GitHub.

    Já instalou? Para atualizar
    {{ sistema === 'windows' ? 'Windows' : 'macOS e Linux' }} 
    {{ atualizar[sistema] }}
  2. 2

    Baixe as declarações deste projeto

    Salve o {{ arquivo }} na pasta raiz do repositório do projeto, a mesma do package.json ou do pom.xml.

    ✓ Baixado: {{ resultado.marcados }} de {{ resultado.total }} itens marcados.

    {{ erro }}

    O arquivo leva o que vocês marcaram e escreveram em cada item. Se não quiser versioná-lo, adicione o nome dele ao .gitignore.

  3. 3

    Peça ao agente

    Abra o agente na pasta do projeto e envie:

    Mensagem para o agente 
    {{ pedido }}

    O resultado sai no RELATORIO-LGPD.md. Comece pela seção Declarado × código: são os itens marcados aqui que o código não mostra.

A lgpd-scan não substitui o checklist. O que não fica no código (encarregado, contratos, treinamento) continua sendo respondido aqui.
